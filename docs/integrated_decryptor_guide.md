# 集成GUI解密器使用指南

现在生成的解密器exe文件已经集成了GUI界面，提供更好的用户体验。

## 🎨 新功能特性

### 智能模式切换
- **GUI模式**：默认启动图形界面（推荐）
- **命令行模式**：支持传统命令行操作
- **自动回退**：GUI不可用时自动切换到命令行

### 用户友好界面
- 🔐 现代化的图形界面设计
- 📁 直观的文件选择功能
- 📋 智能的文件类型选择
- 🔓 一键解密操作
- 📊 实时进度显示
- 📝 详细操作日志

## 🚀 使用方法

### 方法1：GUI模式（推荐）

1. **双击运行解密器**
   ```
   双击 xxx_decryptor.exe 文件
   ```

2. **自动检测加密文件**
   - 解密器会自动在同目录查找 `.encrypted` 文件
   - 如果只有一个文件，会自动选择
   - 如果有多个文件，可以手动选择

3. **选择文件类型**
   - 🔍 自动检测（推荐）
   - 📦 压缩包
   - 📁 文件夹
   - 📄 文档
   - 🖼️ 图片
   - 🎬 视频
   - 📋 其他

4. **开始解密**
   - 点击"🔓 开始解密"按钮
   - 观察进度条和日志信息
   - 等待解密完成

5. **处理结果**
   - 解密成功后选择"打开文件"或"显示位置"
   - 解密的文件会保存在同目录

### 方法2：命令行模式

```bash
# 传统命令行用法
xxx_decryptor.exe 加密文件.encrypted 输出文件名

# 强制命令行模式
xxx_decryptor.exe --cli

# 自动模式（在同目录查找加密文件）
xxx_decryptor.exe
```

## ⚠️ 注意事项

### 系统要求
- **操作系统**：Windows 10/11
- **GUI库**：自动检测PyQt6/PySide6
- **内存**：建议至少2GB可用内存
- **磁盘空间**：确保有足够空间存储解密文件

### 使用建议
1. **文件位置**：将解密器与加密文件放在同一目录
2. **类型选择**：优先使用"自动检测"功能
3. **耐心等待**：大文件解密需要时间
4. **备份重要**：解密前备份加密文件

### 故障排除

#### GUI无法启动
- **现象**：直接进入命令行模式
- **原因**：缺少GUI库
- **解决**：系统会自动回退到命令行模式

#### 解密失败
- **检查文件**：确保加密文件完整
- **检查权限**：确保有写入权限
- **查看日志**：检查详细错误信息

#### 文件类型错误
- **重新选择**：尝试不同的文件类型
- **使用自动检测**：让系统智能判断
- **手动重命名**：解密后修改扩展名
