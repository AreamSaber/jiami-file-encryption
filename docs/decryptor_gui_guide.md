# 解密器GUI使用指南

本指南将帮助您使用图形界面解密器进行文件解密操作。

## 🚀 启动解密器GUI

```bash
# 进入项目目录
cd C:\Users\Camellic\PycharmProjects\jiami

# 启动解密器GUI
python decryptor_gui.py
```

## 📋 界面功能详解

### 1. 文件选择区域 📁

- **浏览加密文件...**: 点击选择要解密的 `.encrypted` 文件
- **文件路径显示**: 显示选择的加密文件完整路径

### 2. 文件类型选择区域 📋

选择预期的原始文件类型，帮助系统正确解密和命名输出文件：

- **🔍 自动检测**: 让系统自动检测原始文件类型（推荐）
- **📦 压缩包 (ZIP)**: 解密后输出为ZIP压缩包
- **📁 文件夹**: 解密后恢复为文件夹结构
- **📄 文档文件**: 解密后输出为文档文件 (PDF, DOC等)
- **🖼️ 图片文件**: 解密后输出为图片文件 (JPG, PNG等)
- **🎬 视频文件**: 解密后输出为视频文件 (MP4, AVI等)
- **📋 其他文件**: 解密后输出为通用文件格式

### 3. 输出设置区域 💾

- **输出路径**: 显示解密后文件的保存位置
- **自定义路径...**: 点击自定义输出文件位置
- **解密完成后自动打开文件**: 解密成功后自动打开解密的文件
- **解密完成后显示文件位置**: 解密成功后在文件管理器中显示文件位置

### 4. 操作按钮区域

- **🔓 开始解密**: 开始执行解密操作
- **❌ 取消**: 取消正在进行的解密操作
- **🚪 退出**: 关闭解密器程序

### 5. 进度显示区域 📊

- **进度条**: 显示解密操作的进度百分比
- **状态信息**: 显示当前操作状态和提示信息

### 6. 操作日志区域 📝

- **实时日志**: 显示详细的操作日志和状态信息
- **清空日志**: 清空当前显示的日志内容

## 🔧 使用步骤

### 基本解密流程

1. **启动程序**
   ```bash
   python decryptor_gui.py
   ```

2. **选择加密文件**
   - 点击"浏览加密文件..."按钮
   - 在文件对话框中选择 `.encrypted` 文件
   - 确认文件路径显示正确

3. **选择文件类型**
   - 如果知道原始文件类型，选择对应选项
   - 不确定时选择"自动检测"（推荐）

4. **确认输出设置**
   - 检查自动生成的输出路径
   - 如需自定义，点击"自定义路径..."
   - 选择解密完成后的操作（打开文件/显示位置）

5. **开始解密**
   - 点击"🔓 开始解密"按钮
   - 观察进度条和状态信息
   - 等待解密完成

6. **处理结果**
   - 解密成功：选择打开文件或显示位置
   - 解密失败：查看错误信息并重试

## 📁 文件类型说明

### 自动检测 🔍
- 系统会分析文件内容和文件名
- 自动推断最可能的文件类型
- 适用于大多数情况

### 压缩包 📦
- 适用于ZIP、RAR等压缩文件
- 解密后可以直接解压使用
- 保持原始压缩格式

### 文件夹 📁
- 适用于整个文件夹的加密
- 解密后恢复完整的目录结构
- 包含所有子文件和子文件夹

### 文档文件 📄
- 适用于PDF、Word、Excel等办公文档
- 解密后保持原始格式
- 可以直接用相应软件打开

### 图片文件 🖼️
- 适用于JPG、PNG、GIF等图片格式
- 解密后保持原始图片质量
- 支持各种图片查看器

### 视频文件 🎬
- 适用于MP4、AVI、MKV等视频格式
- 解密后可以正常播放
- 保持原始视频质量

## ⚠️ 注意事项

### 文件安全
1. **密钥保护**: 解密器包含密钥信息，请妥善保管
2. **文件备份**: 解密前建议备份加密文件
3. **安全删除**: 解密成功后可以安全删除加密文件

### 系统要求
1. **操作系统**: Windows 10/11, macOS, Linux
2. **Python版本**: Python 3.8+
3. **GUI库**: PyQt6 或 PySide6
4. **内存**: 建议至少4GB RAM
5. **磁盘空间**: 确保有足够空间存储解密文件

### 性能提示
1. **大文件**: 大文件解密可能需要较长时间
2. **系统资源**: 解密过程会占用CPU和内存
3. **磁盘I/O**: 确保磁盘有足够的读写性能

## 🔧 故障排除

### GUI无法启动
```bash
# 检查GUI库安装
pip install PyQt6
# 或
pip install PySide6

# 运行测试
python test_decryptor_gui.py
```

### 解密失败
1. **检查文件**: 确保加密文件完整且未损坏
2. **检查权限**: 确保对输出目录有写入权限
3. **检查空间**: 确保磁盘有足够的可用空间
4. **查看日志**: 检查操作日志中的详细错误信息

### 文件类型错误
1. **重新选择**: 尝试选择不同的文件类型
2. **自动检测**: 使用"自动检测"选项
3. **手动重命名**: 解密后手动修改文件扩展名

### 程序无响应
1. **等待完成**: 大文件解密需要时间，请耐心等待
2. **取消操作**: 点击"取消"按钮停止当前操作
3. **重启程序**: 关闭程序后重新启动

## 💡 最佳实践

### 使用建议
1. **文件命名**: 使用有意义的文件名便于识别
2. **类型选择**: 优先使用"自动检测"功能
3. **路径管理**: 将解密文件保存在易于找到的位置
4. **定期清理**: 定期清理不需要的解密文件

### 安全建议
1. **密钥管理**: 妥善保管解密器程序
2. **访问控制**: 限制对解密器的访问权限
3. **日志清理**: 定期清理操作日志
4. **文件销毁**: 安全删除敏感的解密文件
