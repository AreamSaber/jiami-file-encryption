# GUI界面使用指南

本指南将帮助您使用图形界面进行文件和文件夹加密。

## 🚀 启动GUI界面

```bash
# 进入项目目录
cd C:\Users\Camellic\PycharmProjects\jiami

# 启动GUI界面
python gui/main_window.py
```

## 📋 界面功能

### 1. 文件加密标签页

#### 文件选择区域
- **选择文件**：点击"选择文件"按钮选择单个文件进行加密
- **选择文件夹**：点击"选择文件夹"按钮选择整个文件夹进行加密
- **输出目录**：点击"浏览..."按钮选择加密文件的输出目录

#### 加密设置区域
- **加密配置**：从下拉菜单选择预设的加密配置
  - `standard` - 标准加密（推荐）
  - `high_security` - 高安全性加密
  - `fast` - 快速加密
- **高级选项**：勾选显示更多高级配置选项

#### 操作按钮
- **开始加密**：开始执行加密操作
- **取消**：取消正在进行的加密操作

#### 进度显示
- **进度条**：显示加密进度
- **状态信息**：显示当前操作状态

#### 日志区域
- 显示详细的操作日志和错误信息

### 2. 文件解密标签页

- **解密说明**：显示如何使用生成的解密器
- **解密器列表**：显示可用的解密器程序
- **刷新列表**：更新解密器列表

### 3. 设置标签页

- **系统信息**：显示系统和软件版本信息
- **选项设置**：
  - 加密完成后自动打开输出目录
  - 删除原文件前确认

## 🔧 使用步骤

### 加密单个文件

1. **启动GUI**：运行 `python gui/main_window.py`
2. **选择文件**：点击"选择文件"按钮，选择要加密的文件
3. **选择输出目录**：点击"浏览..."按钮，选择输出目录
4. **选择加密配置**：从下拉菜单选择加密配置（推荐使用"standard"）
5. **开始加密**：点击"开始加密"按钮
6. **等待完成**：观察进度条和状态信息
7. **查看结果**：加密完成后会显示结果对话框

### 加密文件夹

1. **启动GUI**：运行 `python gui/main_window.py`
2. **选择文件夹**：点击"选择文件夹"按钮，选择要加密的文件夹
3. **选择输出目录**：点击"浏览..."按钮，选择输出目录
4. **选择加密配置**：从下拉菜单选择加密配置
5. **开始加密**：点击"开始加密"按钮
6. **等待完成**：文件夹加密可能需要更长时间
7. **查看结果**：加密完成后会显示结果对话框

## 📁 输出文件

加密完成后，输出目录中会包含：

- **加密文件**：`原文件名.encrypted`
- **解密器**：`原文件名_decryptor.exe`
- **批处理文件**：`原文件名_decryptor.bat`（如果exe生成失败）
- **使用说明**：`原文件名_decryptor_README.txt`（如果exe生成失败）

## 🔓 解密文件

### 方法1：双击解密器（推荐）
1. 找到生成的 `*_decryptor.exe` 文件
2. 双击运行解密器
3. 解密器会自动找到同目录下的加密文件
4. 解密完成后会在同目录生成原文件

### 方法2：使用批处理文件
1. 找到生成的 `*_decryptor.bat` 文件
2. 双击运行批处理文件
3. 按提示输入加密文件路径和输出路径

### 方法3：命令行运行
```bash
# 使用exe解密器
./文件名_decryptor.exe 加密文件.encrypted 输出文件名

# 使用Python脚本
python 文件名_decryptor.py 加密文件.encrypted 输出文件名
```

## ⚠️ 注意事项

1. **文件安全**：
   - 解密器包含密钥信息，请妥善保管
   - 不要修改解密器文件内容
   - 建议将解密器与加密文件分开存储

2. **系统要求**：
   - Windows 10/11
   - Python 3.8+
   - PyQt6 或 PySide6

3. **性能提示**：
   - 大文件加密可能需要较长时间
   - 文件夹加密会递归处理所有子文件
   - 建议关闭其他占用CPU的程序

4. **错误处理**：
   - 如果加密失败，查看日志区域的错误信息
   - 确保有足够的磁盘空间
   - 确保对输出目录有写入权限

## 🔧 故障排除

### GUI无法启动
```bash
# 检查GUI库安装
pip install PyQt6
# 或
pip install PySide6

# 运行诊断工具
python tools/diagnose.py
```

### 文件选择器无响应
- 确保系统文件对话框正常工作
- 尝试重启程序
- 检查系统权限设置

### 加密失败
- 检查文件是否被其他程序占用
- 确保有足够的磁盘空间
- 检查文件路径中是否包含特殊字符

### 解密器无法运行
- 确保解密器与加密文件在同一目录
- 检查Windows安全设置
- 尝试使用批处理文件或Python脚本

## 💡 最佳实践

1. **备份重要文件**：加密前先备份原文件
2. **测试解密器**：加密完成后立即测试解密功能
3. **安全存储**：将解密器存储在安全位置
4. **定期更新**：保持软件版本最新
5. **文档记录**：记录加密文件的用途和位置
